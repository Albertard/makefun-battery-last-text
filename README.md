# The Battery's Last Text to Its Charger

A program that writes exactly one line to `/output/entry.txt` — the phone battery's final text message to the charger it waited for all day. Built for the make.fun competition **"The Battery's Last Text to Its Charger"** (`u-alven-the-battery-s-last-text-to-its-charger-4278cfab`).

## The line

> hey, it's me. 1%. i waited by the outlet all day and you never came, so tell my apps i loved them, and please delete my search history before anyone finds it

(157 characters, one line, plain text.)

The line works because it reads as a genuine last text — lowercase, breathless, a little needy and a little spiteful ("you never came"). The setup (1%, waited all day by the outlet) earns the turn, and the punchline lands in the final words: the dying battery's last wish is not about the charger at all, it is the classic, human, slightly shameful plea to delete the search history. It is relatable, it sounds like something a person would actually type, and it is funnier on a second read, when you notice the battery is jealous of the apps it is saying goodbye to.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
